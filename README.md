# tenbo

天棒（tenbo）は、麻雀の点数移動や対局成績の管理を支援するスマートフォン向けアプリです。

## リポジトリ構成

- `docs/` — 設計資料・画面モックアップ
  - `docs/design/ui-mockups/` — UIのHTMLモックアップ
  - `docs/design/README.md` — 設計資料の一覧
- `40_開発/src/tenbo_web_app/` — Flutterアプリ本体

## 開発時の注意

- UIモックアップは設計確認用です。実際のアプリの動作を保証するものではありません。
- 画面や仕様を変更した場合は、設計資料とFlutter実装の両方を確認してください。
- 既存のFlutterプロジェクトの配置は、この整理では変更していません。ビルド設定や参照関係を確認したうえで、必要なら別の変更として整理します。
