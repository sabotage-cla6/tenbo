``` mermaid 
flowchart TD
    %% スタイル定義
    classDef screen fill:#1e293b,stroke:#38bdf8,stroke-width:2px,color:#fff;
    classDef modal fill:#334155,stroke:#f43f5e,stroke-width:2px,color:#fff;

    %% 画面（メインノード）
    TOP[TOP画面 / ホーム]:::screen
    CREATE[対局作成・設定画面]:::screen
    JOIN[部屋参加画面]:::screen
    LOBBY[対局準備ロビー画面]:::screen
    GAME[対局（卓）画面]:::screen
    INITIAL[場決め・起家決め]:::screen
    RESULT[最終結果・清算画面]:::screen
    HISTORY[過去の対局履歴画面]:::screen

    %% モーダル / ダイアログ（サブノード）
    RULE_MODAL[[ルール詳細モーダル]]:::modal
    SCORE_MODAL[[点数入力モーダル]]:::modal
    CONFIRM_FINISH[[対局中断ダイアログ]]:::modal

    %% 遷移関係
    TOP -->|「新規卓準備」| CREATE
    TOP -->|「卓に入る」| JOIN
    TOP -->|「履歴を見る」| HISTORY

    HISTORY -->|「戻る」| TOP

    CREATE -->|「ルール設定変更」| RULE_MODAL
    RULE_MODAL -->|「保存」| CREATE
    CREATE -->|「部屋を作成」| LOBBY

    JOIN -->|「部屋ID入力・参加」| LOBBY
    JOIN -->|「キャンセル」| TOP

    LOBBY -->|「退出する」| TOP
    LOBBY -->|「全員準備完了」| INITIAL

    %% 対局画面内の操作（枠なしで直接接続）
    INITIAL -->|「対局開始」| GAME
    GAME -->|「和了 / 流局」| SCORE_MODAL
    GAME -->|「対局中断」| CONFIRM_FINISH
    SCORE_MODAL -->|「結果確定」| GAME
%%    CONFIRM_FINISH -->|「中断する」| TOP

    GAME -->|「全局終了 / トビ判定」| RESULT

    RESULT -->|「TOPへ戻る」| TOP
    RESULT -->|「同じメンバーで再戦」| LOBBY
```
