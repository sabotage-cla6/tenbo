# 設計資料

## UIモックアップ

画面イメージのHTMLは [ui-mockups](./ui-mockups/) にまとめています。

| ファイル | 画面 |
|---|---|
| [top.html](./ui-mockups/top.html) | トップ画面 |
| [home.html](./ui-mockups/home.html) | ホーム画面 |
| [signup.html](./ui-mockups/signup.html) | 新規アカウント登録 |
| [login.html](./ui-mockups/login.html) | ログイン |
| [rule-settings.html](./ui-mockups/rule-settings.html) | ルール詳細設定 |
| [terms-of-service.html](./ui-mockups/terms-of-service.html) | 利用規約 |
| [privacy-policy.html](./ui-mockups/privacy-policy.html) | プライバシーポリシー |

これらは画面イメージ用のHTMLであり、Flutterアプリの実装コードとは区別して管理します。
仕様や画面構成を変更した場合は、対応する実装とこの資料の整合性も確認してください。
